# Fungal Footing #

## About ##
Adds fungal infection to Minecraft. If you stand on Mycelium there's a chance you become infected. Infected players will lose health similar to the poison effect but instead it's infectious! So beware of infected players as they might spread their infection to you.

This mod was made as a joke from an idea given by [TelepathicGrunt](https://www.curseforge.com/members/telepathicgrunt/projects)
